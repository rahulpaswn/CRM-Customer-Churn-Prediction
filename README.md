# 🏦 CRM Customer Churn Prediction System

## 📌 Project Overview
This project predicts customer churn for a banking CRM system using Machine Learning.
The model identifies high-risk customers and provides actionable business insights.

## 🎯 Business Objective
- Predict customer churn probability
- Segment customers into risk levels
- Help CRM teams take retention actions

## 📊 Dataset
- 66,736 banking customers
- Features: tenure, transactions, balances, loans, cards, activity
- Target: Churn (0 = No, 1 = Yes)

## 🧠 ML Workflow
1. Data Cleaning & EDA
2. Churn vs Non-Churn Analysis
3. Feature Selection
4. Model Training (Logistic Regression, Random Forest)
5. Model Evaluation (ROC-AUC)
6. Churn Probability & Risk Scoring

## 🤖 Models Used
- Logistic Regression (Baseline)
- Random Forest (Final Model)

## 📈 Key Results
- Random Forest achieved better recall and ROC-AUC
- High-risk customers identified using churn probability
